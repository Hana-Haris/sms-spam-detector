SMS Shield – SMS Spam Detection

Project Description

SMS Shield is a Python-based mini-project that detects whether an SMS message is spam or legitimate.

Technologies Used

- Python
- Streamlit
- Machine Learning
- Text Processing

Files

- "app.py" – Main application file
- "requirements.txt" – Required Python libraries

How to Run

Install the required libraries and run the application using Streamlit.

pip install -r requirements.txt
streamlit run app.py
